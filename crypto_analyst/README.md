# Crypto Analyst

AI-assisted crypto market analysis engine.

## Scope
- public market data only
- no exchange account access
- no order placement
- trend / momentum / volatility / support-resistance analysis
- structured JSON report for dashboard or AI explanation

## Quick start
```bash
cd crypto_analyst
pip install -r requirements.txt
python main.py --symbol BTCUSDT --interval 1h
```

The engine is designed for analysis and paper-testing. It does not execute trades.
